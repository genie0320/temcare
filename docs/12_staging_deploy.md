# 시연 환경 배포 작업 계약

> 근거 결정: `docs/06_decisions.md` **#40**(콘텐츠 정본·배포 방침) · **#41**(이 문서의 결정 사항)
> 이 문서는 **어디에 무엇을 어떻게 올릴지의 계약**이다. 벗어나야 할 이유를 찾으면 진행하지 말고 먼저 물어볼 것.

## 1. 무엇을 만드나

**고객(원장·이해관계자)이 아무 때나 열어보는 시연 주소.**
지금까지의 `make demo`(Cloudflare Tunnel)는 "내 컴퓨터가 켜져 있는 동안만"이라
고객에게 링크를 미리 줄 수 없었다. 이 배포는 그걸 대체한다.

| | `make demo` (터널) | 이번 배포 (스테이징) |
|---|---|---|
| 사는 동안 | 내 터미널이 켜져 있는 동안 | 항상 |
| 주소 | 켤 때마다 바뀜 | 고정 |
| 여는 범위 | **고객 앱만** | **고객 앱 + 관리자** |
| 용도 | 옆에서 같이 보기 | 고객이 혼자 CRUD까지 테스트 |

둘 다 남긴다. 터널은 여전히 "지금 이 화면 좀 보세요"에 쓸모가 있다.

## 2. 최우선 제약 — **이식성**

운영은 **다른 인프라(국내 리전)로 새로 배포**하는 것이 전제다(#37·#40).
따라서 이 스테이징은 **언제든 통째로 옮길 수 있어야** 한다.

- **Docker 이미지 한 장**으로 만든다. 호스트를 바꿔도 같은 상자를 옮기면 된다.
- **특정 업체 전용 기능에 의존하지 않는다** — 서버리스 함수, 업체 전용 스토리지 SDK,
  업체 전용 빌드팩 설정 등. 표준 컨테이너 + 표준 PostgreSQL만 쓴다.
- 업체가 주는 것은 "상자를 돌려주는 것"과 "TLS를 붙여주는 것"까지다.

이 비용은 지금 반나절, 나중에 지불하면 며칠짜리다.

## 3. 구조 — 한 주소에 몰기

```
https://<고정주소>/
  ├─ /            고객 앱 (app-web 빌드 결과)
  ├─ /admin-ui/   관리자 (admin-web 빌드 결과)
  ├─ /api/        Django
  └─ /django-admin/  Django 기본 admin (그대로 둠)
                       └── PostgreSQL (외부 관리형)
```

**쪼개지 않는 이유** — `SESSION_COOKIE_SAMESITE = "Lax"`라 화면과 API의 오리진이
갈리면 세션 쿠키가 전송되지 않는다. 우회하려면 `SameSite=None` + CORS로 보안 등급을
낮춰야 한다(#40 결정2). 시연 편의를 위해 인증 구조를 건드리지 않는다.

정적 파일은 **WhiteNoise**로 Django가 직접 서빙한다(현재 미설치). 두 SPA는
클라이언트 라우팅이므로 **각자의 경로 아래에서 `index.html` 폴백**이 필요하다.

## 4. 비용 — 월 1만원 이내 (사용자 결정)

- **앱: 최소 유료 플랜.** ★ **잠자기(idle sleep) 있는 무료 티어를 쓰지 않는다.**
  15분 유휴 후 첫 접속이 50초 흰 화면이 되어, 고객이 "안 되네요" 하고 닫는다.
  이 환경의 존재 이유가 사라진다.
- **DB: 관리형 PostgreSQL 무료 티어.** `DATABASE_URL`만 넣으면 되게 이미 준비돼 있다(#16).
  ★ **가입 후 일정 기간이 지나면 DB를 삭제하는 무료 티어를 고르지 않는다.**
  (붙일 때 약관을 실제로 확인할 것 — 요금·정책은 자주 바뀐다.)
- 커스텀 도메인은 이번 범위 밖. 업체가 주는 기본 주소로 시작한다.

## 5. ★ 배포 전에 반드시 — 안 하면 열면 안 된다

### 5-1. 로그인 시도 제한 (필수)

**현재 없다**(2026-08-04 확인). 관리자 로그인 화면이 인터넷에 있는데 시도 제한이
없으면 비밀번호를 무한정 찍어볼 수 있다. 관리자를 공개하는 이번 결정의 **전제 조건**이다.

- 대상: 관리자 로그인(`/api/accounts/login/`)과 고객 로그인·가입.
- 실패 시도 기준으로 IP + 계정 단위. 초과 시 429.
- **차단은 감사로그에 남긴다** — `action="deny"`. 보안 사건이므로 같은 장부에 남긴다
  (`AdminResourcePermission`이 권한 거부를 남기는 것과 같은 논리).

### 5-2. 시연 환경 표시 (필수)

해외 리전이라 **실제 환자 정보가 들어가면 개인정보 국외이전 문제**가 생긴다.
고객이 무심코 넣는 것을 막아야 한다.

- 고객 앱·관리자 **양쪽 상단에 항상 보이는 띠**: "시연 환경입니다. 실제 환자 정보를
  입력하지 마세요." 닫을 수 없게 한다.
- 새 설정 `DEMO_BANNER = env.bool("DEMO_BANNER", default=False)`로 켠다.
  운영 배포에서는 꺼진다.

### 5-3. 원상복구 경로 (필수)

고객이 CRUD로 데이터를 망가뜨리는 것은 **정상이고 오히려 원하는 것**이다.
되돌릴 방법이 없으면 고객이 마음 놓고 못 누른다.

- 관리 명령 하나로 시드 상태 복원(`seed_demo` + `import_doctor_content` 재실행).
- 콘텐츠 정본이 git이므로(#40) **재배포만으로도 콘텐츠는 원상복구된다.**
- ★ **자동 재시드를 배포마다 돌리지 않는다.** 고객이 테스트하던 내용이 예고 없이
  사라진다. 반드시 명시적 실행.

### 5-4. 배포 기본값 점검

- `DJANGO_SECRET_KEY` **환경변수 필수.** 현재 개발용 기본값이 코드에 박혀 있다.
  배포 환경에서 기본값이면 **기동을 거부**하게 한다(조용히 뜨면 아무도 모른다).
- `DEBUG=False` · `ALLOWED_HOSTS` · `CSRF_TRUSTED_ORIGINS` 환경변수로.
- 호스트가 TLS를 종료하고 평문 HTTP로 넘기므로 `SECURE_PROXY_SSL_HEADER`를 설정한
  뒤에 `SECURE_SSL_REDIRECT`를 켠다. 순서를 지키지 않으면 리다이렉트 루프가 난다
  (`config/settings.py`의 기존 주석 참고 — 실제로 CI를 깨뜨린 적이 있다).
- `python manage.py check --deploy` 통과.

## 6. ★ `PUBLIC_DEMO`를 켜지 말 것 — 충돌 지점

`docs/11_audit_viewer.md` §4-4가 **`PUBLIC_DEMO=True`면 감사로그 API를 404로 막으라**고
정했다. 그건 **터널 시연**을 위한 규칙이다(고객 앱만 열고 관리자는 통째로 잠금).

이번 스테이징은 **관리자 전 기능을 테스트하는 것이 목적**이라 감사로그도 열려야 한다.
따라서:

```
스테이징:  DEBUG=False   PUBLIC_DEMO=False   DEMO_BANNER=True
터널 시연: DEBUG=True    PUBLIC_DEMO=True    (그대로)
```

- `PUBLIC_DEMO=True`로 배포하면 **감사로그 화면이 404가 되어 원인을 한참 찾게 된다.**
- `dev-login`(무인증 관리자 진입)은 `DEBUG=False`이므로 이미 막힌다 — 이중으로 안전하다.

## 7. CI/CD

- `main` 브랜치 + **CI 전 잡 초록**일 때만 배포한다(#40 결정3).
  푸시 즉시 공개된다는 것은 **다른 세션의 실수도 즉시 공개된다**는 뜻이다.
- 배포 단계에서 `migrate`를 실행한다. 시드는 실행하지 않는다(§5-3).

## 8. 이번에 만들지 않을 것

| | 이유 |
|---|---|
| **PWA**(manifest·서비스워커) | 미구현. 다음 작업. ★ 서비스워커 캐시 때문에 **고객 폰에 옛 화면이 남는** 문제가 있어, 배포 방식과 **같이** 설계해야 한다. 따로 붙이면 반드시 밟는다 |
| **GPS 주변 한의원** | `clinic` 모델에 **좌표 필드가 없다**(주소·전화만 있음). 위도·경도 추가 + 좌표를 어떻게 채울지(주소 변환 API vs 수기) 결정이 먼저 |
| 커스텀 도메인 | 기본 주소로 시작 |
| 백업·모니터링 | 가짜 데이터 전용 환경이라 1차 범위 밖 |

## 9. 검증

1. **실제 브라우저로 한 바퀴** — 관리자 로그인 → 마스터 CRUD 한 바퀴 → 고객 가입 →
   문진 → 결과 → 처방 → 한의원. 스크린샷으로 사용자에게 보고.
2. **변이 테스트**(`CLAUDE.md` §5-2) — 시도 제한을 지우고 테스트를 돌린다.
   실패하지 않으면 그 안전장치는 없는 것과 같다.
3. `make test` · `make lint` 초록. `check --deploy` 통과.
4. **커밋만 하지 말고 푸시까지.** 커밋은 사용자가 요청할 때만.

## 10. 다른 세션과의 충돌

세 세션이 병렬로 돈다.

| 세션 | 주로 만지는 곳 |
|---|---|
| 원장 콘텐츠 입력 (`docs/10`) | `apps/content/` · `doctor_data/` · `seed_demo.py` |
| 감사로그 화면 (`docs/11`) | `apps/audit/` · `admin-web/` · **`config/settings.py`** · `seed_demo.py` |
| **이 작업** | `config/settings.py` · `Dockerfile` · `.github/workflows/` · `Makefile` |

**`config/settings.py`가 감사로그 세션과 겹친다.** 수정 전에 `git status`와 `git log`로
확인하고, 충돌하면 덮어쓰지 말고 사용자에게 알릴 것.
