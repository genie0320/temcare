# 1차 개발 범위 (체크리스트)

> 정본은 `spec/*.xlsx` 의 `단계` 열이다. 이 문서는 그것을 작업 순서로 펼친 것.
> 관리자 25화면 · 고객 30화면.

## 1차 완료 기준

mock 판별로 **가입 → 문진 → 결과 → 처방 → 협력 한의원 연결** 한 바퀴가 실제로 돈다.
완성도의 기준은 환자용이 아니라 **영업용** — 원장이 다른 원장에게 시연할 수 있으면 끝.

> **스플래시 → 문진 → 결과 티저(비로그인) → 로그인+약관동의+권한안내 → 상세결과+처방** 순.
